CloudSync local prototype

Run the local prototype

Requires Python 3.10 or newer. No third-party packages are needed.

  1. From the project directory, run python3 server.py.
  2. Keep the terminal open. The server prints a one-time API token.
  3. Open http://127.0.0.1:8000/ in this computer's browser and paste the token into the workspace form.
  4. Upload, list, and download test files from the page. Press Ctrl+C in the terminal to stop the server.

The server binds only to 127.0.0.1. Uploaded file data and its SQLite index are stored outside the public site directory in ~/.local/share/cloudsync-local/. Set CLOUDSYNC_DATA_DIR to choose another local directory outside this project. Set PORT to change the default port 8000.

Install as a web app

On supported browsers, use the Install app button or the browser menu's Install/Add to Home Screen action. The app shell and informational pages can be cached for offline viewing; file API requests and user file data are never cached. File operations still require the local server to be running.

Browsers do not allow an app to request every device permission automatically during installation. This prototype requests no notification, camera, microphone, location, or broad file-system permissions. The file picker grants access only to files you explicitly choose.

Installation requires a secure context: localhost is treated as secure for development; a deployed site must use HTTPS.

API

  • GET /api/v1/status — public process status.
  • GET /api/v1/files — list stored file metadata (bearer token required).
  • POST /api/v1/files — store a JSON file payload (bearer token required).
  • GET /api/v1/files/{id}/download — download a stored file (bearer token required).

Uploads are limited to 5 MiB. The token changes every time the server starts; use the current token printed by that process. Example request body:

{"name":"notes.txt","content_base64":"SGVsbG8h"}

There is no account system, deletion endpoint, cross-device sync engine, backup, or production security configuration. Do not bind this prototype to a public interface or upload sensitive data.
