CloudSync local prototype

Local data notice

Files uploaded through this prototype are stored on the machine running the server, under ~/.local/share/cloudsync-local/ by default. The SQLite database stores file names, sizes, and upload timestamps. No remote account or analytics service is configured.

The API token is printed in the server terminal and held in the current browser tab's session storage. Treat uploaded files and the token as sensitive. This local development prototype is not a production privacy or security solution.
