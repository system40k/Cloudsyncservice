A simple workspace for your files.

Upload files to this machine, review what is stored, and download them again through a small authenticated API. This is a single-host prototype—not multi-device synchronization or a production cloud service.

Open local workspaceAPI documentation

Install this app from your browser's menu when available. Installation does not grant file or device permissions.

What works in this prototype

The local API persists uploaded files and metadata on disk. It is intentionally small and does not claim to be a production sync platform.

Upload

Send a file of up to 5 MiB using the browser interface and a per-run bearer token.

Review

List stored files with their names, sizes, and upload timestamps.

Download

Retrieve a stored file through an authenticated endpoint. Data stays on this host.
