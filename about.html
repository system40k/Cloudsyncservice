CloudSync local prototype

About this prototype

This is a small, single-host file storage prototype. Its browser interface uploads files to a Python server, displays stored metadata, and downloads files from the same machine.

What it provides

  • Local file upload, listing, and download API endpoints
  • A bearer token generated for each server run
  • SQLite metadata and file data stored outside the public site directory

Limitations

This is not a multi-device synchronization system or production cloud service. It has no user accounts, sharing, file deletion, backups, or production hardening. It binds to localhost only.
